# Python - import & modules

Python project on importing functions and modules.

## Files

| File | Description |
| ---- | ----------- |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3`. |
| `1-calculation.py` | Imports arithmetic functions from `calculator_1.py`. |
| `2-args.py` | Prints the number of and the list of its arguments. |
| `3-infinite_add.py` | Prints the result of the addition of all arguments. |
| `4-hidden_discovery.py` | Prints all names defined by the compiled module `hidden_4.pyc`. |
| `5-variable_load.py` | Imports the variable `a` from `variable_load_5.py`. |
| `100-my_calculator.py` | Command-line calculator using operators `+`, `-`, `*` and `/`. |
| `101-easy_print.py` | Prints `#pythoniscool` without using `print` (2 lines). |
| `102-magic_calculation.py` | `magic_calculation` function matching a given bytecode. |
| `103-fast_alphabet.py` | Prints the uppercase alphabet without string literals. |
| `add_0.py` | Module providing `add`. |
| `calculator_1.py` | Module providing `add`, `sub`, `mul` and `div`. |
| `variable_load_5.py` | Module providing the variable `a`. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
