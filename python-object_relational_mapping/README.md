# Python - Object-relational mapping

This repository contains scripts and projects for working with MySQL databases using Python. The tasks focus on connecting to a MySQL server, executing SQL queries, and later integrating with SQLAlchemy ORM.

## Directory

- `0-select_states.py` - Lists all states from the database `hbtn_0e_0_usa`.

## Requirements

- Python 3.x
- MySQLdb module
- MySQL server running on localhost at port 3306

## Usage

```bash
./0-select_states.py <username> <password> <database>
```
