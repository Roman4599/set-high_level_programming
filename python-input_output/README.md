# Python - Input & output

Python project on reading and writing files, JSON serialization and parsing.

## Files

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Prints the whole content of a UTF-8 file to stdout, read through a `with` statement. |
| `1-write_file.py` | Writes a string to a UTF-8 file, creating or overwriting it, and returns the number of characters written. |
| `2-append_write.py` | Appends a string to the end of a UTF-8 file, creating it when missing, and returns the number of characters added. |
| `3-to_json_string.py` | Returns the JSON representation of an object as a string. |
| `4-from_json_string.py` | Returns the Python object represented by a JSON string. |
| `5-save_to_json_file.py` | Writes an object to a text file using its JSON representation. |
| `6-load_from_json_file.py` | Returns the object described by a JSON file. |
| `7-add_item.py` | Adds the command line arguments to a list and saves it to `add_item.json`. |
| `8-class_to_json.py` | Returns the dictionary description of an object for JSON serialization. |
| `9-student.py` | Defines a `Student` class with a `to_json` method. |
| `10-student.py` | Defines a `Student` class whose `to_json` can be filtered by attribute names. |
| `11-student.py` | Defines a `Student` class that can be reloaded from a dictionary. |
| `12-pascal_triangle.py` | Returns Pascal's triangle of `n` rows as a list of lists of integers. |
| `100-append_after.py` | Inserts a line of text after each line of a file containing a given string. |
| `101-stats.py` | Reads log lines on stdin and prints the total file size and the lines per status code. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
