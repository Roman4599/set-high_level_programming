# Python - Input & output

Python project on reading files and printing their content to stdout.

## Files

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Prints the whole content of a UTF-8 file to stdout, read through a `with` statement. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
