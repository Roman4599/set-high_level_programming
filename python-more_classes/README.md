# Python - More Classes and Objects

Python project on object-oriented programming: classes, objects, and static/class methods.

## Files

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | Empty class `Rectangle`. |
| `1-rectangle.py` | Rectangle with private `width`/`height` and property validation. |
| `2-rectangle.py` | Adds `area()` and `perimeter()` methods. |
| `3-rectangle.py` | Adds `__str__` printing the rectangle with `#`. |
| `4-rectangle.py` | Adds `__repr__` to recreate instances with `eval()`. |
| `5-rectangle.py` | Prints `Bye rectangle...` on instance deletion. |
| `6-rectangle.py` | Tracks `number_of_instances` class attribute. |
| `7-rectangle.py` | Adds `print_symbol` for custom string representation. |
| `8-rectangle.py` | Adds `bigger_or_equal` static method. |
| `9-rectangle.py` | Adds `square` class method. |
| `101-nqueens.py` | Solves the N queens puzzle using backtracking. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
