# Python - if/else, loops, functions

Python basics: conditional statements, loops, and functions.

## Files

| File | Description |
| ---- | ----------- |
| `0-positive_or_negative.py` | Assigns a random signed number and prints whether it is positive, zero, or negative. |
| `1-last_digit.py` | Assigns a random signed number and prints its last digit with a comparison. |
| `2-print_alphabet.py` | Prints the lowercase ASCII alphabet, not followed by a new line. |
| `3-print_alphabt.py` | Prints the lowercase ASCII alphabet except `q` and `e`. |
| `4-print_hexa.py` | Prints numbers 0 to 98 in decimal and hexadecimal. |
| `5-print_comb2.py` | Prints two-digit combinations of the numbers 0 to 99. |
| `6-print_comb3.py` | Prints all possible different combinations of two digits. |
| `7-islower.py` | Checks for a lowercase character. |
| `8-uppercase.py` | Prints a string in uppercase followed by a new line. |
| `9-print_last_digit.py` | Prints and returns the last digit of a number. |
| `10-add.py` | Adds two integers and returns the result. |
| `11-pow.py` | Computes `a` to the power of `b` and returns the value. |
| `12-fizzbuzz.py` | Prints numbers 1 to 100 with FizzBuzz substitutions. |
| `13-insert_number.c` | Inserts a number into a sorted singly linked list. |
| `lists.h` | Header for the singly linked list functions. |
| `100-print_tebahpla.py` | Prints the ASCII alphabet in reverse, alternating case. |
| `101-remove_char_at.py` | Creates a copy of a string, removing the character at position `n`. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
