# Python - Classes and Objects

Python project on object-oriented programming: classes and objects.

## Files

| File | Description |
| ---- | ----------- |
| `0-square.py` | Empty class `Square`. |
| `1-square.py` | Square with a private `size` attribute. |
| `2-square.py` | Square with size validation in `__init__`. |
| `3-square.py` | Adds an `area()` method. |
| `4-square.py` | Adds getter/setter for `size`. |
| `5-square.py` | Adds `my_print()` method. |
| `6-square.py` | Adds a `position` attribute. |
| `100-singly_linked_list.py` | `Node` and sorted `SinglyLinkedList` classes. |
| `101-square.py` | Square printable with `print()`. |
| `102-square.py` | Square with comparison operators by area. |
| `103-magic_class.py` | `MagicClass` matching the given bytecode. |

## Requirements

- Ubuntu 20.04 LTS
- python3 (version 3.8.5)
- Code follows PEP 8 style (`pycodestyle`)
